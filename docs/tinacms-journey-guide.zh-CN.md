# 精品行程后台操作说明

进入网站后台后选择「精品行程」。您只需要修改文字和图片；右侧或另一个浏览器标签页用于查看网页效果。无需操作文件名、代码或数据路径。后台在手机上可以查看，但日常编辑建议使用电脑。

## 编辑或新建路线

在「精品行程」列表中，可用中英文目的地、主题或路线名称搜索。点击路线名称即可编辑；点击「新建行程」即可创建路线。新路线默认是草稿，先在「1. 基本信息」填写英文路线名称、简介、季节、难度、起终点、路线概览、价格说明和首图。天数会根据每日行程自动计算，页面网址也会自动生成。

普通编辑顺序为：基本信息、行程概览、行程亮点、每日行程、包含与不包含、适合人群、图片、保存与发布。最后的「高级设置」通常无需打开。

## 亮点与每日行程

「行程亮点」可以一次粘贴多条英文内容，每行自动成为一条亮点，空行会自动清理。路线图片可按内容需要继续添加，并可拖动或使用前移、后移调整顺序。

在「每日行程」点击「添加一天」，只需填写当日标题、交通与住宿、每日正文和图片。每一天建议使用 1–6 张，但不会限制继续添加。段落之间留一个空行。拖动当天卡片或点击上移、下移可调整顺序，第几天和总天数会自动更新。删除一天前会再次确认。

图片可选择原始比例、16:9 横图、4:3 横图、3:4 竖图或 9:16 竖图；位置可选择大图通栏、图片在左、图片在右或双图并排。手机页面会自动改为上下排列。只有需要补充独立引言、今日体验、实用提醒、图片英文说明、画面重点或 Option A/B 时，才展开当天的高级内容。

## 图片库

点击「选择或上传图片」后，可按文件名或文件夹查找图片，例如 `laoyao`、`shaxi`。目前不能根据图片画面自动识别搜索。「图片英文说明」用于搜索引擎和无障碍读屏，不是图片库搜索标签，也不会显示成网页图片标题。

以后上传图片时，请使用小写英文、短横线和清楚的地点或主题，例如 `dali-erhai-sunset.webp`、`shaxi-friday-market.webp`。替换图片时请使用不同的唯一文件名，避免浏览器继续显示旧缓存。不要在文件名中加入客户姓名、邮箱或其他个人信息。

## 保存与发布

在「8. 保存与发布」中：

- 点击「保存草稿」只保存后台内容，网站访客看不到。
- 本地编辑时，保存草稿后可点击「预览草稿」查看完整页面；这个按钮不会发布路线。
- 点击「发布行程」会先显示路线名称、天数、首图和页面网址，确认后才发布。
- 已发布路线修改后，点击「更新已发布内容」。

必填内容缺失或页面网址重复时，后台会用中文说明原因并保留当前填写内容。尚未保存时，可使用页面顶部后台自带的 **Reset** 放弃本次修改；它不会删除已经保存的路线。
