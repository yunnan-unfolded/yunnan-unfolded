# 精品行程后台操作说明

进入网站后台后，选择「精品行程」。您只需要修改表单中的文字和图片；需要预览时，在另一个浏览器标签页打开对应路线。无需操作文件名、代码或数据路径。建议使用电脑完成编辑。

## 1. 编辑已有路线

打开「精品行程」，可用中文或英文目的地、主题和路线名称进行查找，再选择 **Yunnan, Slowly**。编辑内容按 1–11 个中文栏目排列；先展开需要修改的栏目，再编辑其中的英文网站内容。页面顶部出现的英文 **Save** 是后台自带按钮，日常发布操作优先使用「11. 发布状态」中的中文按钮。「后台搜索关键词」只帮助后台查找，不会显示在网站上。

如果行程列表没有搜索框，请联系网站维护人员检查搜索功能开关和后台索引配置。运营者不需要接触任何 Token 或技术配置。

## 2. 查找和更换图片

展开含有图片的栏目，点击「上传图片」，从图片库选择或上传图片。图片库依据文件名和文件夹查找，可输入 `laoyao`、`shaxi` 等名称；目前不能根据画面内容自动识别搜索。选择图片后填写「图片英文说明」：它用于搜索引擎和无障碍读屏，不是图片库搜索标签，也不会显示成网页图片标题。

未来上传图片时，请使用小写英文、短横线和清楚的地点或主题，例如 `dali-erhai-sunset.webp`、`shaxi-friday-market.webp`、`laoyao-mountain-hiking.webp`。不要使用 `IMG_1234.jpg`、`微信图片001.jpg` 或 `final-final-2.jpg`，也不要在文件名中加入客户姓名、邮箱或其他个人信息。请按路线或目的地建立清晰文件夹。

## 3. 新增一天

展开「6. 每日行程」，在每日安排末尾添加一项。填写当日标题、路线、住宿、正文和今日体验。拖动条目可调整顺序；保存时系统会自动更新第几天和总天数。减少天数并保存时会再次确认。

## 4. 调整图文版式

在某一天的图片区域，用中文示意卡选择图片在上、图片在左、图片在右、双图并排或仅文字，再选择小图、标准图或大图。每张图片还可选择自动、横图、竖图或方图，以及画面重点。手机页面会自动变为上下排列。

## 5. 保存草稿

新路线默认是草稿。打开「11. 发布状态」，点击「保存草稿」。草稿不会出现在首页、行程列表、网站地图或公开详情页，可以放心多次修改。

## 6. 发布或更新

准备完成后，打开「11. 发布状态」。系统会先显示路线名称、天数、首图和页面网址。点击「发布行程」并确认；已发布路线再次修改时点击「更新已发布内容」。缺少必填内容时，后台会用中文提示并阻止发布。

## 7. 放弃未保存的修改

尚未保存时，可使用页面顶部后台自带的 **Reset** 放弃本次修改；它不会删除已经保存的路线。若不确定，请先关闭当前编辑页，确认不要保存后再重新打开。
